# sveltekit-i18n.github.io

Build output for <https://sveltekit-i18n.github.io/>. Nothing here is edited by
hand.

The site's source lives in
[`sveltekit-i18n/lib`](https://github.com/sveltekit-i18n/lib) under `site/`,
and renders the documentation straight out of that repository's `docs/`. The
`Site` workflow there builds it and replaces this repository's contents on
every push to `master` that touches `site/**` or `docs/**`.

Open issues and pull requests against `lib`, not here.
