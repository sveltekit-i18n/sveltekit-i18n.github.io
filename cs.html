Internacionalizace pro SvelteKit

npm install sveltekit-i18n

# deno add npm:sveltekit-i18n

Přečíst dokumentaci GitHub

Svelte 5 a Node 22, Bun 1.2 nebo Deno 2 a novější. Pouze ESM.

Proč sveltekit-i18n

  • Stavěné pro SvelteKit Instance na každý požadavek, takže jazyk jednoho návštěvníka nikdy nedorazí na stránku druhého.
  • Jedna instalace Jádro i parser Curly jsou součástí. Nic dalšího se nepřidává a reaktivní graf zůstává jeden.
  • Načítá, co route potřebuje Loader se spustí, když sedí jeho jazyk i route — jednou za období platnosti.
  • Jedna reaktivní instance Svelte 5 runes místo stores: vlastnosti se čtou, metody se awaitují.
  • Typované klíče i parametry Slot schema zúží, co t() a l() přijmou — až na parametry jednotlivých zpráv.
  • Rozšiřitelné Pipe extensions přidává instanci další povrchy — třeba Svelte stores.

Rychlý start

  1. Popiš překlady, které aplikace načítá.

    // src/lib/translations/index.js
import { I18n } from 'sveltekit-i18n';

export const config = {
  loaders: [
    {
      locale: 'en',
      key: 'common',
      loader: async () => (await import('./en/common.json')).default,
    },
  ],
};

export const i18n = new I18n(config);

  2. Čti je z instance. Text se řídí aktivním jazykem.

    <script>
  import { i18n } from '$lib/translations';
</script>

<h1>{i18n.t('common.greeting', { name: 'World' })}</h1>

<button onclick={() => { i18n.locale = 'cs'; }}>
  {i18n.t('common.switch')}
</button>
