Internacionalizace pro SvelteKit

npm install sveltekit-i18n

# bun add sveltekit-i18n
# deno add npm:sveltekit-i18n

Přečíst dokumentaci GitHub

Svelte 5 a Node 22, Bun 1.2 nebo Deno 2 a novější. Pouze ESM.

Proč sveltekit-i18n

  • Stavěné pro SvelteKit sveltekit-i18n/kit propojí hooky, layouty i komponenty: na serveru instance na každý požadavek, takže jazyk jednoho návštěvníka nikdy nedorazí na stránku druhého, v prohlížeči jedna na kartu.
  • Jedna instalace Jádro i parser Curly jsou součástí. Nic dalšího se nepřidává a reaktivní graf zůstává jeden.
  • Načítá, co route potřebuje Loader se spustí, když sedí jeho jazyk i route — jednou za období platnosti a parametry route.
  • Jedna reaktivní instance Svelte 5 runes místo stores: vlastnosti se čtou, metody se awaitují.
  • Typované klíče i parametry Slot schema zúží, co t() a l() přijmou — až na parametry jednotlivých zpráv. Vite plugin @sveltekit-i18n/typegen ho vyplní z tvých překladů.
  • Rozšiřitelné Pipe extensions přidává instanci další povrchy — třeba Svelte stores.

Rychlý start

  1. Popiš překlady, které aplikace načítá, a napoj je na SvelteKit.

    // src/lib/i18n.js
import { defineI18n } from 'sveltekit-i18n/kit';

export const config = {
  fallbackLocale: 'en',
  loaders: [
    {
      locale: ['en', 'cs'],
      namespace: 'common',
      loader: async ({ locale, namespace }) => (await import(`./translations/${locale}/${namespace}.json`)).default,
    },
  ],
};

export const { handle, load, use, get } = defineI18n(config, {
  preferredLocale: (event) => event.cookies?.get('lang'),
});

// src/hooks.server.js — fills <html lang="%lang%" dir="%dir%"> in src/app.html
export { handle } from '$lib/i18n';

// src/routes/+layout.server.js and src/routes/+layout.js
export { load } from '$lib/i18n';

  2. Čti je z instance. Text se řídí aktivním jazykem.

    <!-- src/routes/+layout.svelte -->
<script>
  import { use } from '$lib/i18n';

  let { data, children } = $props();

  use(() => data);
</script>

{@render children()}

<!-- any component below it -->
<script>
  import { get } from '$lib/i18n';

  const i18n = get();
</script>

<h1>{i18n.t('common.greeting', { name: 'World' })}</h1>

<button onclick={() => { i18n.locale = 'cs'; }}>
  {i18n.t('common.switch')}
</button>
