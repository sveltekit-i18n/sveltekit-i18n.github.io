sveltekit-i18n

Internationalisierung für SvelteKit

npm install sveltekit-i18n

Dokumentation lesen GitHub

Svelte 5 und Node 22, Bun 1.2 oder Deno 2 oder neuer. Nur ESM.

Warum sveltekit-i18n

  • Für SvelteKit gebaut Eine Instanz pro Anfrage, damit die Sprache eines Besuchers nie auf die Seite eines anderen gerät.
  • Eine Installation Kern und Curly-Parser sind dabei. Nichts weiter hinzuzufügen, und nur ein reaktiver Graph.
  • Lädt, was eine Route braucht Ein Loader läuft, wenn Sprache und Route passen — einmal pro Gültigkeitsfenster.
  • Eine reaktive Instanz Svelte-5-Runes statt Stores: Eigenschaften werden gelesen, Methoden awaited.
  • Typisierte Schlüssel und Parameter Ein schema-Slot verengt, was t() und l() annehmen — bis zu den Parametern jeder Nachricht.
  • Erweiterbar Die extensions-Pipe legt weitere Oberflächen auf die Instanz — etwa Svelte-Stores.

Schnellstart

  1. Beschreibe die Übersetzungen, die die App lädt.

    // src/lib/translations/index.js
import { I18n } from 'sveltekit-i18n';

export const config = {
  loaders: [
    {
      locale: 'en',
      key: 'common',
      loader: async () => (await import('./en/common.json')).default,
    },
  ],
};

export const i18n = new I18n(config);

  2. Lies sie von der Instanz. Der Text folgt der aktiven Sprache.

    <script>
  import { i18n } from '$lib/translations';
</script>

<h1>{i18n.t('common.greeting', { name: 'World' })}</h1>

<button onclick={() => { i18n.locale = 'cs'; }}>
  {i18n.t('common.switch')}
</button>
