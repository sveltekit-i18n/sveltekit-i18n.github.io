Hřiště

Každý panel níže řídí skutečnou instanci přes veřejné API. Změň vstup a knihovna odpoví — nic tady není nahrávka.

# Formáty zpráv

Jádro samo žádný formát zpráv nemá: slot vyplňuje parser. Curly přichází s tímto balíčkem, ICU je alternativa postavená přímo na jádře.

Výstup

You have 1,234 messages.

Žádná hlášení. Hlášení nikdy nevyhodí výjimku — placeholder vezme svou náhradu a zbytek zprávy se vyhodnotí.

Zobrazit kód 
import { I18n } from 'sveltekit-i18n';

const i18n = new I18n({
  initLocale: locale,
  translations: { [locale]: { inbox: message } },
  parserOptions: { onReport: (report) => reports.push(report) },
});

i18n.t('inbox', payload);

# Předzpracování

Z vnořených překladů se stávají ploché klíče, které čte t(). Jak daleko se zajde, určuje režim.

full

  • nav.home
  • nav.about
  • tags.0
  • tags.1

preserveArrays

  • nav.home
  • nav.about
  • tags array

none

  • nav object
  • tags array

rawTranslations drží vstup tak, jak přišel; translations je to, co vidíš tady.

Zobrazit kód 
const i18n = new I18n({ initLocale: 'en', preprocess: mode });

i18n.addTranslations({ en: input });

Object.keys(i18n.translations.en);

# Loadery

Loader se spustí, když sedí jeho jazyk i jeho routes na aktuální route, jednou za okno čerstvosti. Načti stejnou route dvakrát a sleduj, jak druhý pokus neudělá nic.

Vyber jazyk a route, pak načti.

Zobrazit kód 
const i18n = new I18n({
  initLocale: 'en',
  loaders: [
    // No routes: every route, so it loads once and never again.
    { locale, key: 'common', loader },
    // A string route is an exact match.
    { locale, key: 'home', routes: ['/'], loader },
    // A whole section needs a pattern.
    { locale, key: 'docs', routes: [/^\/docs(\/|$)/], loader },
  ],
});

await i18n.loadTranslations(locale, route);

# Záložní jazyk

Klíč, který aktivní jazyk nemá, se vyhodnotí přes fallbackLocale, místo aby zůstal prázdný.

Klíčcst(key)
titlePřekladyPřeklady
subtitle—Loaded per route
cta—Read the docs

Zálohují se jen chybějící klíče. Co vykreslí klíč chybějící všude, určuje fallbackValue.

Zobrazit kód 
const i18n = new I18n({
  initLocale: 'cs',
  fallbackLocale: 'en',
  translations: { en: complete, cs: partial },
});

i18n.t('subtitle'); // the English text: 'cs' has no such key
